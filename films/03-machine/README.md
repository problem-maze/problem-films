# Film 03 — THE MACHINE THAT DREW EVERY FUTURE

Psychological idea: overthinking and choice paralysis. The machine draws more futures whenever the character hesitates or tries to inspect every possibility. Predicted paths become physical ribbons with tension and weight.

## Current gate

Do **not** expand to 60 seconds yet. The current acceptance target is the approved 12.000 second sequence.

## Approved 12-second sequence

- **0.00–2.00** — one path; the character lifts a foot; before landing, the machine splits the route into three futures.
- **2.00–4.00** — each head turn generates another future; one ribbon wraps the ankle.
- **4.00–6.00** — the character pulls back; reels accelerate; ribbons wrap both wrists; tension travels through shoulders, spine, pelvis, and planted foot.
- **6.00–7.50** — full stop under real tension; no frozen hold: breathing, joint micro-corrections, ribbon tension, reel vibration.
- **7.50–9.00** — visible weight transfer followed by a lateral step into unpredicted black space.
- **9.00–10.00** — only after foot contact and weight acceptance does a small light tile form beneath the foot.
- **10.00–11.00** — wrists and ankle release; predicted routes lose tension and fall with gravity, rebound, collision, and disorder.
- **11.00–12.00** — second step creates a second tile; the machine attempts to print the next future and produces readable emptiness.

## Hook

The machine can draw every possibility, but it cannot draw an action before the character actually commits to it.
