# Problem Films QC

Every approved render must be accompanied by measured evidence.

## Technical gates

- exact duration
- constant frame rate
- expected frame count
- native render resolution declaration
- codec and audio metadata report

## Motion gates

- planted-foot drift check during specified intervals
- limb-length consistency check
- contact and penetration review at wrists, ankles, torso, and floor
- tension-hold continuity review
- release/fall secondary-motion review

## Film 03 close-up evidence

The 12-second Machine proof must include review frames for:

1. ankle wrap
2. wrist tension
3. planted receiving foot
4. release and ribbon fall
5. second tile and blank future output

## Reporting rule

Do not claim a pass unless the relevant check was actually performed on the delivered file or simulation state. Unmeasured items must remain explicitly unverified.
