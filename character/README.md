# Canonical Problem Character

The reusable Problem character uses one stable, faceless, gender-neutral geometric body across films.

## Required articulation

Root, pelvis, lower/upper spine, chest, neck, head, clavicles, upper arms, forearms, wrists, thighs, shins, ankles, and feet.

## Required performance behavior

- Planted feet stay planted.
- Center of mass shifts before a step.
- Pelvis counterbalances the torso.
- Chest and shoulders respond to external forces with believable delay.
- Breathing and micro-corrections keep held poses alive.
- Releasing force produces a small counter-motion.

## Rejected behavior

Limb-length drift, foot sliding, rigid-torso pulling, pose morphing, or arbitrary silhouette changes invalidate a shot.
