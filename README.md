# Problem Films

**Problem Films** is the production repository for the cinematic world of **Problem**.

Problem turns invisible human patterns into physical rules, spaces, machines, and forces. The films are not direct advertisements and do not rely on long explanations. Each film should communicate through action, cause-and-effect, weight, resistance, silence, and visual consequence.

## Canon films

1. **THE MAZE THAT LEARNS YOU** — repeated behavior becomes a maze that learns the route.
2. **THE ECHO THAT MOVED FIRST** — automatic reaction becomes an echo that moves before the person.
3. **THE MACHINE THAT DREW EVERY FUTURE** — overthinking and choice paralysis become a machine that draws more futures whenever the person hesitates.

## Core visual identity

- Background: `#040608`
- Lunar white: `#E1EBF8`
- Functional cyan: restrained and story-driven only
- Faceless, gender-neutral geometric character
- The eye represents pattern observation / learning
- Minimal objects, complex physical cause-and-effect
- No neon-game look, no generic motion-graphics language, no random AI morphing

## Production principle

The visual style may remain minimal, but the movement system underneath must be physically credible: planted feet, weight transfer, articulated spine/chest/pelvis, collision-aware ribbons, secondary motion, gravity, and reproducible rendering.
